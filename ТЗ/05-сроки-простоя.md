## Решение владельца (В-4)

Пороги 7/14 дней одинаковые для всех — неверно: пауза, которая для Кореи тревога, для санкционной Японии норма. Сроки по направлениям:

- **Япония, обычная**: всего около 30 дней. Таможня / лаборатория 5–7, море до Владивостока 3–7, остальное — выкуп и подготовка в Японии.
- **Япония, санкционная** (свыше 1900 см³, гибриды, электро; **мягкие гибриды — не санкционные**): всё как у обычной, но море идёт через Корею — 40–80 дней.
- **Корея**: таможня / лаборатория как у Японии; подготовка и фрахт как у обычной Японии, но на 2–3 дня меньше.
- **Китай**: моря нет. Логистика по Китаю и экспортные документы 10–25 дней; погрузка на автовоз и транзитные документы около 5; таможня / лаборатория как у всех.
- **ЕАЭС**: сроков владелец не давал — остаются 7/14.

Санкционность определяется **галочкой в сделке**, только для маршрута «Япония». Из расчёта не выводится (в калькуляторе нет типа «гибрид»).

## 2.2 Таблица норм

Положить в `deals.html` рядом с `idleDays` (`:254`):

```js
// Норма простоя в днях по маршруту и текущему этапу — сроки владельца
// (см. ТЗ 05). warn — верхняя граница нормального
// срока, после неё жёлтый; bad — красный. Чего нет в таблице — 7/14.
// Ключ этапа — ТЕКУЩИЙ этап сделки (d.stageKey) и его состояние: после
// «Оплата инвойса — пройден» ждём экспорт (выкуп и подготовка), после
// «Экспорт — пройден» ждём прихода (море / автовоз), «Таможня — в процессе» —
// само оформление.
const IDLE_DEFAULT = { warn:7, bad:14 };
const IDLE_NORMS = {
  japan:      { 'invoice:done':{warn:22,bad:30}, 'export:done':{warn:7,bad:14},  'customs:wip':{warn:7,bad:12} },
  japan_sanc: { 'invoice:done':{warn:22,bad:30}, 'export:done':{warn:80,bad:100},'customs:wip':{warn:7,bad:12} },
  korea:      { 'invoice:done':{warn:19,bad:26}, 'export:done':{warn:5,bad:10},  'customs:wip':{warn:7,bad:12} },
  china:      { 'invoice:done':{warn:25,bad:35}, 'export:done':{warn:5,bad:10},  'customs:wip':{warn:7,bad:12} }
};
function idleNorm(d){
  const key = (d.route==='japan' && d.sanctioned) ? 'japan_sanc' : d.route;
  const byRoute = IDLE_NORMS[key];
  return (byRoute && byRoute[(d.stageKey||'') + ':' + (d.stageState||'')]) || IDLE_DEFAULT;
}
```

Числа — из диапазонов владельца: `warn` = верх диапазона, `bad` = примерно плюс треть. Владелец правит их в этой таблице, больше нигде.

Как получены: Япония обычная — 30 всего минус таможня 7 минус море 7 → выкуп/подготовка до ~22; Корея — минус 3 дня; Китай — 10–25 логистика, 5 автовоз; санкционная Япония — море 40–80.

## 2.3 Применить в списке

`deals.html:518-520`:
```js
const days = idleDays(d.stageAt || d.createdAt);
const norm = idleNorm(d);
const cls = d.archived ? 'good' : (days >= norm.bad ? 'bad' : (days >= norm.warn ? 'warn' : ''));
const idleLabel = d.archived ? 'завершена' : 'без движения ' + pluralDays(days) + (norm !== IDLE_DEFAULT ? ' · норма до ' + norm.warn : '');
```

Хвост «· норма до 22» показывать только там, где норма взята из таблицы, — иначе он везде и не информативен. Если строка не влезает в ширину строки списка (`white-space:nowrap` у `.idle`, `:86`) — убрать хвост совсем, оставить только цвет.

Проверка `stageState` в индексе: `dealIndexRow` уже отдаёт `stageState` (`:103`), клиент считает его в `saveDeal` (`:1334`) — ничего добавлять не надо.

## 3. Две мелочи, замеченные при выполнении ТЗ 04

Исполнитель ТЗ 04 заметил, но по правилам не трогал. Делаются здесь, тем же коммитом.

**3.1 Лог сделки: «в процессе» пишется словом «снят».** `api/deals.js:171-172`, `describeChanges`: слово для состояния выбирается как `done → 'пройден'`, `skip → …`, всё остальное → `'снят'`. Состояние `wip` («в процессе») попадает в «всё остальное». Добавить ветку: `a.state === 'wip' ? 'в процессе'`. Проверить: отметить любой этап «В процессе» → в «Истории изменений» строка «этап «…» — в процессе».

**3.2 Подсказка в чеке калькулятора при зафиксированном курсе.** `index.html:1464`, строка «Цена ТС с расходами до РФ» с подсказкой `переведено в рубли по текущим курсам, банк. комиссия учтена`. Когда калькулятор открыт из сделки с зафиксированным курсом инвойса (`lockedRates()` возвращает значения — см. `index.html:754`), подсказка неверна. Сделать: если `lockedRates()` — текст `переведено в рубли по курсу на DD.MM.YYYY (оплата инвойса), банк. комиссия учтена`, дата из `RECALC_CTX.ratesLock.at`; иначе — как сейчас. Проверить: открыть из сделки с оплаченным инвойсом «открыть в калькуляторе» → в чеке подсказка с датой; обычный расчёт — прежний текст.
