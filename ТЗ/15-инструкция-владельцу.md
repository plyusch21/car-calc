# ТЗ 15 — что сделать владельцу (пошагово)

Три части: настроить вход в Telegram (BotFather), положить три переменные в Vercel, запустить исполнителя. Минут 15. Ничего из полученных значений не вставлять в чаты — ни аналитику, ни Claude Code.

---

## Часть 1. BotFather — разрешить вход на наш сайт

1. В Telegram открыть **@BotFather** и запустить его мини-приложение: кнопка «Открыть» / «Open» внизу чата (если её нет — ссылка `t.me/botfather?startapp`).
2. В списке ботов выбрать **бота калькулятора** (того, из которого открывается мини-приложение car-calc).
3. Раздел **Login Widget**. Если на экране одно поле «Enter URL» и кнопка **Switch to OpenID Connect Login** — нажать эту кнопку (поле URL не заполнять): это переключение со старого виджета на новый механизм.
4. На новом экране два списка, нужны оба:
   - **Redirect URIs** → «Add a Redirect URI» → `https://car-calc-eight.vercel.app/` — с косой чертой в конце, BotFather требует точного совпадения;
   - **Trusted Origins** (ниже) → добавить `https://car-calc-eight.vercel.app` — без косой черты.
5. Вверху этого же экрана — **Client ID** (число, у нас `8646054246`) и **Client Secret** (скрыт точками, копируется кнопкой справа). Копировать сразу в Vercel (часть 2), не в заметки и не в мессенджер. «Revoke» не нажимать — это выпуск нового секрета, старый перестанет работать.

## Часть 2. Vercel — три переменные

1. Открыть vercel.com → проект **car-calc** → вкладка **Settings** → слева **Environment Variables**.
2. Добавить три переменные. У каждой отметить окружения **Production** и **Preview** (Development можно не ставить):

   | Key | Value |
   |---|---|
   | `TELEGRAM_LOGIN_CLIENT_ID` | Client ID из BotFather |
   | `TELEGRAM_LOGIN_CLIENT_SECRET` | Client Secret из BotFather |
   | `SESSION_SECRET` | случайная строка, см. ниже |

3. **Как получить `SESSION_SECRET`.** На Mac: Программы → Утилиты → **Терминал**, вставить и нажать Enter:
   ```
   openssl rand -hex 32
   ```
   Появится строка из 64 букв и цифр — это и есть значение. Скопировать её целиком в Vercel. Нигде больше не сохранять: если когда-нибудь потеряется, просто сгенерировать новую — все сотрудники один раз войдут заново.
4. Нажать **Save** у каждой переменной. Переменные подхватываются при следующем деплое — его сделает пуш исполнителя, отдельно ничего нажимать не надо.

## Часть 3. Запуск исполнителя

1. Убедиться, что другая сессия Claude Code сейчас не идёт (правило: одна за раз).
2. Приложение Claude на Mac → **Code** → **New session** → папка `car-calc` → модель **Fable**.
3. Перетащить из Finder файл `car-calc/ТЗ/15-вход-через-telegram.md` в поле ввода и написать:

   > Переменные TELEGRAM_LOGIN_CLIENT_ID, TELEGRAM_LOGIN_CLIENT_SECRET, SESSION_SECRET в Vercel добавлены, адрес в BotFather зарегистрирован. Выполни приложенное ТЗ целиком, без пропусков. После выполнения сам пройди раздел «Проверить» из этого ТЗ, напиши по каждому пункту — сошлось или нет, и только потом коммит и пуш в main по правилам CLAUDE.md.

4. Ждать. В ТЗ есть стоп-точка: если исполнитель напишет, что Telegram отдаёт не тот id пользователя, что в мини-приложении, — не просить его «придумать», а переслать сообщение аналитику.
5. Когда исполнитель отчитается о пуше — написать аналитику «15 готов».

## Часть 4. Проверка своими глазами (после «15 готов»)

1. На телефоне открыть **Safari** (не Telegram) → `car-calc-eight.vercel.app`.
2. Должен быть экран с кнопкой **«Войти через Telegram»**. Нажать.
3. Откроется страница Telegram: ввести номер телефона → в приложении Telegram придёт запрос на подтверждение входа → разрешить.
4. Safari вернётся в калькулятор. Проверить: вкладка **Настройки** → есть **«Доступ к приложению»** (значит, вошёл как владелец, а не как новый пользователь) и стоит твоя тема.
5. Закрыть Safari, открыть снова — должен остаться внутри без повторного входа.
6. В Telegram открыть мини-приложение как обычно — всё как раньше.

Если на шаге 4 оказался «новым пользователем» с экраном «Доступ ожидает подтверждения» — не одобрять себя, написать аналитику: это как раз случай несовпадения id.

## На будущее

- Отозвать вход конкретному сотруднику — как и сейчас: Настройки → Доступ к приложению → закрыть доступ.
- Разлогинить всех разом — заменить `SESSION_SECRET` в Vercel на новый и сделать любой пуш (или Redeploy в Vercel).
- Client Secret утёк — в BotFather в том же разделе Login Widget нажать **Revoke** (выпустит новый секрет) и обновить `TELEGRAM_LOGIN_CLIENT_SECRET` в Vercel.
