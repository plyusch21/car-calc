# ТЗ 11 — Китай: автозаполнение по ссылке на объявление che168.com

Задача: на маршруте «Китай» в поле «Автозаполнение» можно вставить ссылку на объявление che168.com (二手车之家 / Autohome) — поля формы заполняются со страницы объявления и из справочника параметров модели, как сейчас работает Encar на Корее.

Зачем: 90 % китайских объявлений менеджеры получают ссылками с che168; сейчас приходится переписывать цифры руками или копировать текст. Все нужные калькулятору поля (цена, пробег, дата, объём в см³, мощность, КПП, привод, тип топлива) у che168 лежат в открытом виде — ИИ для цифр не нужен, ошибок распознавания не будет.

Что проверено аналитиком 17.09.2026 (живой тест через браузер, не из кода):
- Страница объявления `https://www.che168.com/dealer/<dealerid>/<infoid>.html` отдаётся **сервером целиком** (SSR), без входа и капчи, кодировка **GB2312/GBK** — декодировать через `new TextDecoder('gbk')` (в Node с полным ICU есть; если в среде Vercel `gbk` не поддержан — взять `iconv-lite`, это единственная допустимая новая зависимость).
- В HTML есть скрытые поля: `car_infoid`, `car_carname` (название модели по-китайски, например `探岳 2023款 280TSI 两驱豪华Plus进阶版`), `car_price` (**в 万元**, `15.48` = 154 800 ¥), `car_mileage` (**в 万公里**, `1.72` = 17 200 км), `car_firstregtime` (`2023/05` — дата постановки на учёт), `car_specid` (id комплектации в справочнике Autohome), `car_isselled` (`1` = продано), `car_publicdatestr`.
- Блок «车辆档案» (`ul.basic-item-ul`, `li > span.item-name` + текст): `变速箱`, `排量`, `发动机` (`1.4T 150马力 L4`), `车身颜色`, `驱动方式` (`前置前驱`), `过户次数`, `排放标准`.
- Описание продавца: `<p id="messageBox">…</p>` — свободный текст, часто содержит **дату выпуска** («2023年3月3日出厂»), пометки о покраске/ремонте, опциях.
- Справочник параметров по `specid` — открытый JSON без ключа: `https://cacheapigo.che168.com/CarProduct/GetParam.ashx?specid=<specid>` (тоже GBK). Структура `result.paramtypeitems[].paramitems[{name, value}]`. Нужные пары: `排量(mL)` → см³ (`1395`), `最大马力(Ps)` → л.с. (`150`), `最大功率(kW)` → кВт (`110`), `变速箱类型` (`湿式双离合变速箱(DCT)`) и `变速箱` (`7挡湿式双离合`), `驱动方式` (`前置前驱`), `燃料形式` / `能源类型` (`汽油`, `柴油`, `纯电动`, `插电式混合动力`, `增程式`, `油电混合`), `车型名称`, `厂商指导价(元)`.
- **Не проверено:** доступна ли страница с серверов Vercel (США). Из России и из США через браузер открывается; блокировка по IP дата-центра возможна. Поэтому первый шаг ТЗ — проверка с прода, см. раздел «Что сделать», п. 0.
- dongchedi.com (懂车帝) с любых наших адресов (Россия, США) отдаёт **пустую страницу** на все URL, включая внутренние API, — судя по всему, сайт закрыт для доступа извне Китая. В это ТЗ не входит; см. «Допущения».

Выполнять после ТЗ 10 (тексты карточки): 10 ставит placeholder «Введите текст», это ТЗ меняет его на «Введите текст или ссылку».

Модель: Opus. Одна сессия.

## Что сделать

### 0. Сначала — проверить доступ с прода

В `api/parse-listing.js` добавить отладочное действие только для владельца (по образцу `debugFreeform`): `body.debugChe168Url` → сервер делает `fetch` страницы и `GetParam` и возвращает `{status, bytes, hasInfoId, specid, paramStatus}` без разбора. На `/diag` — поле для ссылки и кнопка «Проверить che168». Задеплоить, проверить с прода на 2–3 ссылках. Если страница с Vercel **не открывается** (пусто, редирект на проверку, 403) — остановиться, записать в `РЕШЕНИЯ.md` и сообщить владельцу: дальнейшие пункты без доступа не имеют смысла. Отладочное действие оставить — оно пригодится, если che168 начнёт блокировать позже.

### 1. Распознавание ссылки

`isChe168Url(str)`: hostname `che168.com` или `*.che168.com` (включая `m.che168.com`), путь `/dealer/<цифры>/<цифры>.html` или любой путь с `<infoid>.html`. Хвост после `?`/`#` отбросить. Ссылку с `m.che168.com` привести к `www.che168.com/dealer/<dealerid>/<infoid>.html` (если dealerid в мобильной ссылке нет — запросить как есть, che168 редиректит).

### 2. Загрузка и разбор страницы

- `fetch` с заголовками обычного браузера (`User-Agent` десктопного Chrome, `Accept-Language: zh-CN,zh;q=0.9`, `Accept: text/html`), таймаут 10 с, один повтор при сетевом обрыве (как `fetchEncarUrl`). Тело — `arrayBuffer` → декодировать GBK.
- Извлечь скрытые поля регулярками по `<input id="car_xxx" type="hidden" value="…"`: `infoid`, `carname`, `price`, `mileage`, `firstregtime`, `specid`, `isselled`.
- Нет `car_infoid` → ошибка `che168: не нашли данные объявления на странице (возможно, ссылка не на объявление или сайт закрыл доступ)`. `car_isselled = 1` → ошибка `che168: объявление помечено как проданное`.
- Из `ul.basic-item-ul`: пары `item-name → значение` (текст после `</span>` до `</li>`, `&nbsp;` и пробелы внутри названий убрать: `变  速  箱` → `变速箱`). Из `<p id="messageBox">` — описание продавца, HTML-сущности раскодировать.

### 3. Справочник параметров по specid

`GET https://cacheapigo.che168.com/CarProduct/GetParam.ashx?specid=<specid>` → GBK → JSON. Собрать словарь `имя → значение` по всем `paramtypeitems[].paramitems[]`. Если запрос упал — не ошибка: продолжать по данным страницы (объём из `排量` в литрах × 1000, мощность из `发动机` «150马力»), в `notes` добавить «параметры модели не загрузились».

### 4. Структурные поля (побеждают ИИ)

- `carPrice` = `car_price × 10000`, целое (юани).
- `mileage` = `car_mileage × 10000`, целое (км).
- `volumeCm3` = `排量(mL)` из справочника; нет — `排量` со страницы (л × 1000); для `纯电动` — не заполнять.
- `power` = `最大马力(Ps)`, `powerUnit = 'ls'`; нет — `最大功率(kW)` и `'kvt'`; нет — число перед `马力` из строки `发动机`.
- `transmission`: по `变速箱类型` и `变速箱`: содержит `双离合`/`DCT`/`DSG` → `robot`; `CVT`/`无级` → `variator`; `手动`/`MT` → `manual`; `固定齿比`/`单速`/`电动车单速` → `reductor`; иначе `自动`/`AT`/`手自一体` → `auto`. Нет данных → null.
- `drivetrain`: `前置前驱`/`前驱` → `front`; `后驱`/`前置后驱`/`中置后驱` → `rear`; `四驱`/`全时`/`适时`/`分时`/`双电机四驱` → `full`.
- `engineType`: `汽油`/`油电混合`/`插电式混合动力`/`增程式` → `ben` (гибриды в калькуляторе считаются как бензин — так же, как сейчас у ИИ-разбора; в `notes` добавить «гибрид: <тип по-русски>»); `柴油` → `dis`; `纯电动` → `electric`.
- Дата (`prodMonth`/`prodYear`): если в описании продавца есть дата выпуска (`出厂` рядом с `YYYY年M月[D日]`) — взять её; иначе `car_firstregtime` (`YYYY/MM`) и в `notes` — «дата по постановке на учёт, выпуск может быть раньше». Возраст в форме пересчитается сам (`applyAgeFromDate`, как сейчас).

### 5. ИИ — только для текста

Собрать одну строку и отдать в `callGeminiText()` (с резервом `callGigaChat`, параллельно с п. 3, как в `parseEncarListing`): `车型名称` (или `car_carname`), `车身颜色`, `排放标准`, `过户次数`, описание продавца. Из ответа ИИ брать **только** `model`, `carTrim`, `condition`, `notes` (модель на английском — ИИ переводит китайское название: `探岳` → `Volkswagen Tayron`, `280TSI 两驱豪华Plus进阶版` → в `carTrim`). Числа и справочные поля из п. 4 перекрывают всё, что вернул ИИ. Если ИИ недоступен — `model` = `car_carname` как есть (по-китайски), остальное пусто; это не ошибка.

`notes` дополнить сведениями со страницы, если ИИ их не упомянул: цвет, количество владельцев (`过户次数`), стандарт выбросов, «гибрид …» / «дата по постановке на учёт …» из п. 4. Одной строкой через « · », без переносов.

### 6. Ответ и ошибки

Формат ответа — тот же объект, что у Encar (`source:'che168'`), чтобы `runListingParse()` на клиенте ничего не менять. Ошибки — `502` с текстом `che168: …` (как `Encar: …`). Ветка в обработчике — сразу после ветки Encar, до общего ИИ-разбора; ссылка на che168, вставленная на **любом** маршруте, обрабатывается так же (маршрут на сервере не приходит).

### 7. Клиент

В карточке «Автозаполнение» на маршруте `china`: placeholder `Введите текст или ссылку`, подсказка `Можно вставить ссылку на объявление che168.com` (одной строкой, стиль как у Кореи после ТЗ 10). Больше на клиенте ничего.

### 8. `diag.html`

Кнопку из п. 0 оставить; рядом — кнопка «Разобрать che168» (обычный вызов без `debug`), чтобы владелец мог сверить результат по ссылке, не открывая калькулятор.

## Допущения (владелец может возразить)

- **dongchedi.com не делаем** в этом ТЗ: сайт не отдаёт ничего за пределами Китая (проверено из России и из США — пустой ответ на страницы и на API). Через Vercel доступа тем более не будет. Вариант на будущее — «Поделиться → скопировать текст» из приложения 懂车帝 и вставить как текст: это уже работает через ИИ-разбор. Если у тебя dongchedi открывается с телефона — скажи, проверим, что именно и как он отдаёт.
- Цена берётся как есть (`car_price`) — это цена продавца без 过户费; торг не учитываем.
- Гибриды считаются бензином (в калькуляторе типов только три), тип гибрида пишется в заметки.
- Дата выпуска — из описания, если продавец её написал; иначе — дата постановки на учёт с пометкой в заметках.
- Модель и комплектация переводятся ИИ; при недоступном ИИ остаётся китайское название — лучше, чем пусто.

В конце: `bash tools/mapgen.sh`, коммит и пуш в main по правилам CLAUDE.md. Отступления — в `РЕШЕНИЯ.md`.
